# Pink Bloom Hair Care — เริ่มต้นใช้งาน

เว็บไซต์ร้านแชมพูออนไลน์ธีมสีชมพู มีสินค้าเริ่มต้น 2 SKU, ตะกร้าสินค้า, แบบฟอร์มสั่งซื้อ, บันทึกออเดอร์ในเบราว์เซอร์, ดาวน์โหลด CSV และพิมพ์ใบแพ็ก/ใบจ่าหน้าของออเดอร์ล่าสุด

## ทดลองเปิดบนเครื่อง
1. แตกไฟล์ ZIP
2. เปิด `index.html` ด้วย Chrome หรือ Safari
3. ทดลองเพิ่มสินค้าและยืนยันคำสั่งซื้อ
4. ในส่วนผู้ดูแล ทดลองดาวน์โหลด CSV และพิมพ์เอกสาร

## ข้อจำกัดของเวอร์ชันเริ่มต้น
- ข้อมูลคำสั่งซื้อเก็บใน Local Storage ของอุปกรณ์/เบราว์เซอร์ที่เปิดเว็บเท่านั้น ไม่ได้ส่งเข้าร้านหรือ Google Sheets อัตโนมัติ
- ยังไม่มีระบบชำระเงิน, บัญชีผู้ดูแล, ตรวจสต็อกแบบหลายผู้ใช้ หรือเชื่อมบริษัทขนส่ง
- รูปสินค้าเป็นภาพประกอบอีโมจิ สามารถเปลี่ยนเป็นภาพจริงได้ภายหลัง
- ก่อนเปิดขายจริง ต้องเชื่อมฐานข้อมูลส่วนกลางและทดสอบความปลอดภัย/PDPA

## ปรับข้อมูลสินค้า
เปิด `index.html` แล้วค้นหาตัวแปร `const products` ในส่วน `<script>` จากนั้นแก้ SKU, ชื่อ, รายละเอียด, ราคา และสต็อกของสินค้าได้

## เตรียม Google Sheets
สร้าง Google Sheet ชื่อ Pink Bloom Orders และสร้างชีต:
- `Products`: SKU, Name, Description, Price, Stock, Tag
- `Orders`: OrderID, CreatedAt, Customer, Phone, Address, Note, SKU, ProductName, Qty, UnitPrice, Subtotal, Total, Status

ไฟล์ `google-apps-script.gs` เป็นตัวอย่างสคริปต์ฝั่ง Google Apps Script สำหรับบันทึกออเดอร์ ต้องตั้งค่าและทดสอบก่อนเชื่อมกับหน้าเว็บ

## เผยแพร่ด้วย GitHub + Vercel
1. สมัคร/เข้าสู่ระบบ GitHub และสร้าง repository ใหม่ เช่น `pink-bloom-hair-care`
2. อัปโหลด `index.html` (และไฟล์ที่ต้องใช้) เข้า repository
3. เข้า Vercel แล้วเลือก Add New → Project → Import Git Repository
4. เลือก repository นี้ แล้วกด Deploy (เป็นเว็บ static ไม่ต้องใส่ Build Command; Output Directory ใช้ค่าเริ่มต้น)
5. เปิด URL ที่ Vercel แสดงให้เพื่อทดสอบ

## หมายเหตุเรื่องข้อมูลส่วนบุคคล
ข้อมูลชื่อ เบอร์โทร และที่อยู่เป็นข้อมูลส่วนบุคคล ควรจำกัดสิทธิ์เข้าถึง ไม่เผยแพร่ชีตเป็นสาธารณะ และแจ้งวัตถุประสงค์การเก็บข้อมูลให้ลูกค้าทราบ
